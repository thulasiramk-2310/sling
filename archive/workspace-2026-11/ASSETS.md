# Asset provenance and quality

All environment geometry and surface maps were authored for this project. No photographs, textures, 3D files, branding, or source code from the reference portfolio were copied. Architectural source pages below were used as reference only, not downloaded as assets.

| Asset | Source and rights | Current quality |
| --- | --- | --- |

| `public/models/palm.glb` | Original, same script | Curved trunk and modeled individual frond leaflets; instanced at runtime |
| `public/models/shore-temple.glb` | Original, same script | Development architectural study: paired stepped shrines, stone courses, aedicules, relief figures and enclosure; not a scan or measured reconstruction |
| `public/models/brihadisvara.glb` | Original, same script | Development architectural study: tiered vimana, octagonal crown, pilasters, relief figures, mandapa, Nandi pavilion, cloisters, gateway; not a measured reconstruction |

| Water, birds, traffic, trees, exhibits | Original application code | Animated procedural development assets |
| Ambient sound | Original, generated Web Audio filtered noise | Optional abstract ocean ambience, not a field recording |

## Reproducible pipeline

`npm run assets` builds geometry, generates surface maps, and compresses the GLBs using lossless EXT_meshopt_compression. Requires Python 3, Pillow and installed npm dependencies. `asset_backend.py` writes glTF directly from the original geometry definitions when Blender's Python modules are unavailable.

For a working Blender installation: `blender -b -t 2 --python scripts/build-assets.py`, followed by `python3 scripts/build-textures.py` and `node scripts/optimize-assets.mjs`. This Blender branch is supplied but was **not executed successfully on the delivery host**: the installed executable cannot load `libsycl.so.9`. Delivered GLBs were generated with the direct exporter, not Blender. Both paths use the same authored geometry definitions. Unit scale is metres, Blender uses Z-up, output glTF uses Y-up.

Static geometry is batched by material. Palm meshes and background trees are instanced. Meshopt decodes with Drei's bundled decoder and needs no remote decoder service. Sand and stone use small WebP maps; KTX2 is not implemented for these small development maps. Destination code and GLBs load during approach. Loaded destinations stay resident for reverse travel. Per-building LODs, photogrammetry, baked AO and authored high-detail sculptural assets remain future work.

These environments are clearly labeled development studies in the site. They should not be represented as photorealistic, historically exact reconstructions, or final production art. Camera distances and destination spacing are deliberately compressed.
